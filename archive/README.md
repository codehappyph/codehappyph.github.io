# Historical website snapshot

The previous site and its supporting asset directories were copied here before the homepage refresh. HTML, CSS, JavaScript, and image files are preserved byte-for-byte. Existing template placeholders, missing references, external dependencies, expired event links, and historical pricing remain part of the original snapshot; they are not current offerings.

Preview `/archive/` using the local server documented in the root README. Some original absolute links navigate back to the current root homepage. The original page metadata is retained; the root `robots.txt` excludes this directory from crawling. The archive is not linked from the new main navigation or sitemap.

Do not put deployment configuration, credentials, or private training materials here.
